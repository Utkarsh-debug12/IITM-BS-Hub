# Contributing to IITM-BS-Hub

Thanks for helping fellow IITM BS students! Every note, fix and solution counts.

## Ways to contribute

- Add or improve **lecture notes**
- Add **weekly assignment** explanations (after the deadline has passed)
- Add **GrPA** approaches and solutions in any language
- Add cheat sheets, useful links and practice material
- Fix typos, errors or broken links

## Before you start

1. Check the [open issues](https://github.com/Utkarsh-debug12/IITM-BS-Hub/issues) and existing files to avoid duplicates.
2. For big additions (a whole course, say), open an issue first so we can agree on the structure.

## Workflow

1. Fork the repo and clone your fork.
2. Create a branch: `git checkout -b add-course-week-topic`
3. Make your changes.
4. Commit with a clear message: `git commit -m "Add Week 2 notes for Database Management Systems"`
5. Push and open a Pull Request describing what you added.

## File and folder rules

- One top-level folder per course, named in `Title-Case-With-Hyphens`.
- Inside each course: `Notes/`, `Weekly-Assignments/`, `GrPAs/`, `Resources/`.
- Notes: `Week-XX-Topic-Name.md`. Assignments: `Week-XX-GA.md`. GrPAs: `GrPA-N.md`.
- GrPA solutions go in `GrPAs/Week-XX/solutions/<language>/`.
- Write in Markdown. Start each notes file with a header giving the course, term and topics.

## Quality checklist

- [ ] Explanations are clear, and solutions say **why** they work
- [ ] Code has been tested
- [ ] Sources and original authors are credited
- [ ] No official slides, videos or copyrighted material copied in
- [ ] No solutions for live or ongoing assessments

## Academic integrity

Do **not** submit solutions to open assignments, quizzes or exams. Solutions may be added only after the submission deadline. By contributing you agree your work is released under the repository's [CC BY-NC-SA 4.0 license](LICENSE).

## Be kind

Be respectful and constructive in issues and pull requests. We are all here to learn.
