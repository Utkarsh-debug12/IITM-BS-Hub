## 🎯 About

Studying online while managing work, college or family is hard. **IITM-BS-Hub** is a student-run, open-source collection that keeps everything you need for the IITM BS Data Science journey in one organized place.

- 📝 **Lecture notes**: concise, week-wise and easy to revise
- ✅ **Weekly graded assignments**: questions with explained reference solutions
- 💻 **GrPAs**: programming solutions in **multiple languages** with explanations
- 📄 **Practice material**: previous-year style questions and cheat sheets
- 🔗 **Useful links**: books, videos, tools and official resources

Everything is written in **Markdown (`.md`)**, so you can read it on GitHub, in VS Code, Obsidian, or even on your phone.

> 🚧 **Work in progress.** The hub is being built course by course, starting with the Foundation and Diploma levels. Check the progress tables below to see what is available.

## 🏷 Naming Conventions

| Item | Format | Example |
|------|--------|---------|
| Lecture notes | `Week-XX-Topic-Name.md` | `Week-03-Loops-and-Functions.md` |
| Weekly assignment | `Week-XX-GA.md` | `Week-05-GA.md` |
| GrPA | `GrPA-N.md` | `GrPA-2.md` |
| Cheat sheet | `Topic-Cheat-Sheet.md` | `SQL-Cheat-Sheet.md` |
| Folders | `Title-Case-With-Hyphens` | `Programming-in-Python` |

Start every notes file with a short header:

```markdown
# Week 03: Loops and Functions

```

## 🚀 How to Use

**Browse online:** open any course folder on GitHub and read the `.md` files.

**Clone the repo:**

```bash
git clone https://github.com/Utkarsh-debug12/IITM-BS-Hub.git
cd IITM-BS-Hub
```

**Stay updated:**

```bash
git pull origin main
```

**Download as ZIP:** click the green **Code** button, then **Download ZIP**.

💡 **Tip:** press `.` on the repo page to open the web editor, or press `t` to search for any file by name.

## 🤝 Contributing

Contributions are welcome, whether it is notes, a better explanation, a fix, or a solution in another language.

1. **Fork** this repository
2. **Create a branch:** `git checkout -b add-python-week3-notes`
3. **Add your changes** following the structure and naming conventions
4. **Commit:** `git commit -m "Add Week 3 notes for Programming in Python"`
5. **Push:** `git push origin add-python-week3-notes`
6. **Open a Pull Request** with a short description

Please read [CONTRIBUTING.md](CONTRIBUTING.md) for the full guidelines. In short:

- Explain **why** a solution works, not just the code
- Test your code before submitting
- Credit original sources and authors
- Do not upload copyrighted material you do not have the right to share (such as official slides or videos)

Found a mistake? [Open an issue](https://github.com/Utkarsh-debug12/IITM-BS-Hub/issues).

## 🎓 Academic Integrity

This repository follows the spirit of the IITM BS **honor code**.

- Use these materials to **learn and understand**, then write your own solution.
- **Do not copy and submit** any solution as your own work.
- **Do not post solutions for live or ongoing assessments** (open assignments, quizzes or exams). GA and GrPA solutions are added only **after the submission deadline has passed**.
- You are responsible for your own submissions. Misuse can lead to disciplinary action by the institute.

## ❓ FAQ

**Is this an official IITM resource?**
No. It is an unofficial, student-run project.

**Which term do the notes belong to?**
Each file mentions its term in the header. Course content changes between terms, so cross-check with your current syllabus.

**Can I add a solution in another language?**
Yes. Add a folder under `solutions/` named after the language and open a pull request.

**Can I use these notes commercially?**
No. See the license below.
